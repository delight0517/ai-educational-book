자주 묻는 질문

가입하거나 결제해야 하나요?

로컬에서 쓰고 읽는 기능은 계정 없이 사용할 수 있습니다. Only Chat AI와 외부 동기화 기능은 해당 소유 앱과 계정이 필요할 수 있습니다.

모든 AI가 한꺼번에 들어 있나요?

아니요. AI 모델은 각 제공자의 서비스와 이용 조건을 따릅니다. 현재는 Only Chat을 연결하는 어댑터가 포함되어 있습니다.

책을 자동으로 블로그에 올릴 수 있나요?

Secom Career Desk의 게시 시스템과 공식 연결을 준비 중입니다. 현재 다운로드 빌드에서는 자동 게시가 활성화되지 않습니다.

소스와 다운로드는 어디 있나요?

MIT 소스와 Windows ZIP은 공식 GitHub 저장소와 릴리스에서 받을 수 있습니다. ZIP SHA-256을 릴리스 설명과 대조하세요.
